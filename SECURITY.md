# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
[Report a vulnerability](https://github.com/Skryx-L-A/quassel/security/advisories/new).

Include what is affected, how to reproduce it, and which version or commit you tested. Please
remove secrets and personal data from what you send, including recordings, transcripts and
dictionary entries.

This is a one-person project: reports are answered and fixed on a best-effort basis, and there
is no bug bounty.

## Supported versions

Only the current `main` branch and the latest release receive fixes.
