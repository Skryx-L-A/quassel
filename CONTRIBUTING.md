# Contributing

Contributions are welcome. Please open an issue first for larger changes, so the approach can
be agreed on before you invest time.

## Sign-off

Every commit needs a `Signed-off-by` line. With it you confirm the
[Developer Certificate of Origin 1.1](https://developercertificate.org/): in short, that you
wrote the change or otherwise have the right to submit it under this project's license.

Add the line automatically with `git commit -s`. The name and e-mail address must match the
commit author. Use a name you are comfortable having in the public history; a GitHub noreply
address is fine.

If you contribute as part of your job, make sure your employer allows you to contribute under
this license.
